# Security Policy

## Scope

This repository contains documentation and non-secret examples. Do not submit API keys, passwords, cookies, access tokens, personal data, or private account exports.

## Reporting

For a suspected vulnerability in example code or documentation, open a private security report through the repository's GitHub security contact. Include a minimal reproduction and affected file. Do not publish credentials or live account identifiers.

## Operational Safety

Use least-privilege credentials, separate environments, encrypted secret storage, explicit rate limits, and human review for irreversible actions.
